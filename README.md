# La Tabola Gastrobar — propuesta web

Web estática para La Tabola Gastrobar, Logroño. Se puede abrir `index.html` directamente o servir la carpeta con cualquier servidor estático. Preparada para GitHub Pages.

## Investigación y dirección visual

- [La Tabola, web oficial](https://latabola.es/): identidad, dirección, contacto, trayectoria y categorías de carta.
- [Carta digital oficial](https://latabolasierra.revosolo.works/an-store/digital-menu): categorías y productos mencionados. Los precios se consultan allí para evitar duplicar datos que pueden cambiar.
- [Barrafina](https://www.barrafina.com/): composición editorial, escala tipográfica y protagonismo de la comida.
- [La Tavina](https://latavina.com/): contexto gastronómico riojano y forma de presentar la experiencia de mesa.
- [Bodega de La Ardosa](https://www.ar2a.es/): foco en una especialidad reconocible y tono de taberna con personalidad.

La propuesta toma principios visuales de estas referencias y los adapta a una identidad propia. Las dos fotografías gastronómicas son imágenes editoriales generadas para esta maqueta; no muestran platos fotografiados en el local. Sustituir por fotografías propias del restaurante antes de usar la web como canal oficial si se quiere documentar su oferta exacta.

## Contacto y contenido

La dirección, el teléfono y el correo proceden de la web oficial. La carta enlaza a la carta digital del negocio. Las reservas se canalizan por teléfono, sin prometer una integración que no existe.

## Desarrollo

HTML, CSS y JavaScript sin dependencias de compilación. Fuentes DM Sans y DM Serif Display de Google Fonts con alternativas del sistema.
